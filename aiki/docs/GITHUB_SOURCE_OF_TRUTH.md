# GitHub as source of truth

**Status:** **declared**

For multi-year foundation work on AIKI, GitHub is the single source of truth:

| Surface | Use for |
|---------|---------|
| **Issues** | Tasks (pedagogy + tooling tracks) |
| **Discussions** | Architecture ideas (Constitution, RBC-0001, IME) |
| **Pull Requests** | All code/doc changes — everything has history |
| **Milestone** | `v0.1 – CKO-0001 MVP` groups Phase-1 delivery |

Do not treat chat transcripts or local scratch notes as authoritative once an Issue, Discussion, or PR exists.
