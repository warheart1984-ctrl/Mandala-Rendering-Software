**Status:** **declared**

**Source harvest:** Drive D `Governed_State_Spaces_E8*.docx` (June–July 2026 working notes)  
**Role in AIKI:** positioning only — not a runtime dependency

## Design principle

Governance should not rely solely on prohibition lists. Organize the underlying **state space** so constitutionally valid executions are structurally stable, while invalid executions are geometrically difficult, detectable, or costly to reach.

## Four-layer separation

1. **Constitutional** — legal states, invariants, admissibility, evidence, replay, execution equivalence, conformance (mathematically neutral).
2. **Mathematical** — interchangeable reference models for state geometry.
3. **Implementation** — engineering realizations validated by constitutional evidence.
4. **Infrastructure** — models, accelerators, containers; replaceable; no constitutional weight.

## Constitutional Neutrality Principle

No mathematical structure is constitutionally privileged. Reference models are adopted, retained, or replaced only via reproducible evidence, replay, execution equivalence, conformance, and independent validation (**Constitutional Empiricism**).

## Three distinctions (do not conflate)

| Concept | Answers |
|---------|---------|
| Constitutional State Space | Legal *meaning* of a state |
| State Geometry | *Reachability* / adjacency |
| Governance Dynamics | *Preference* / cost / enforcement |
