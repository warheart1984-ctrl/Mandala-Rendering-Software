# AIKI v0.1 Vision

**Status:** **declared**

AIKI treats educational media as governed knowledge infrastructure, not a one-off content workflow.

## Layers

1. **Knowledge** — CKOs, topics, series, taxonomy metadata.
2. **Content production** — CKO → script → narration → visuals → edit artifacts.
3. **Brand / channel** — branding tokens, templates, YouTube config.
4. **Execution** — CLI, storage layout, CI hooks for repeatable production.
5. **Reproducibility (RBC-0001)** — CKO-0001 as permanent reference object; replay + hash archive.

## Math / IME

The Intuitive Mathematics Engine under `aiki/math/` is the math-specific reasoning surface. Math Intuition CKOs (`CKO-MATH-*`) link into IME layers so patterns (e.g. near-round multiplication) are reusable curriculum objects, not ad-hoc tips.

## Non-goals (v0.1 scaffold)

- Live YouTube API upload
- Full TTS / video generation
- Claiming CKO-0001 reproducibility **enforced** before publish freeze
