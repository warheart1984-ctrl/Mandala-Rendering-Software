# AIKI Pedagogy Framework

**Status:** **declared**

## Principles

1. **Pedagogy-first** — learning objectives, key questions, and narrative arc are first-class CKO fields.
2. **Evidence-linked** — definitions and claims point at notes, papers, or worked examples.
3. **Format-agnostic** — a CKO may target YouTube, podcast, newsletter, course module, or tutor dialogue.
4. **Intuition before formalism** — especially for Math Intuition / IME: estimate → structure → compute → explain.
5. **Self-explanation** — every solution carries an intuitive story, the pattern used, and why steps are valid.

## Narrative arc (default video)

| Segment | Duration (guide) | Purpose |
|---------|------------------|---------|
| Intro | 10–20s | Series bumper + hook |
| Context | 60–90s | Why it matters |
| Core | 6–10 min | Sections from `narrative_arc` |
| Summary | 60–90s | Tie to learning objectives |
| Outro | 15–30s | CTA + next teaser |

## Reasoning loop (IME / tutors)

Predict → Solve → Check → Explain.
