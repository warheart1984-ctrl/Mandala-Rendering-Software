# ADR — Adopt CDU-RA v0.1 as declared skeleton blueprint

## Intent

Establish a minimal, honest **Constitutional Discipline Universe Reference Architecture (CDU-RA) v0.1** in documentation so multi-medium products can align on layers and contracts without implying runtime enforcement.

## Decision

1. Place the skeleton at `docs/cdu-ra/` (`README.md` + `CDU-RA-v0.1.md`).
2. Treat adoption as **skeleton** / **declared** documentation — not a CKL/engine conformance gate.
3. Document relationships: CDU-RA = Discipline Universe blueprint; CCALF = learning stewardship; MRS AGENTS.md + charter = MRS agent/runtime binding law; CIEMS / JCR / CRE = related surfaces.
4. Do not modify protected constitutional paths.
5. Record this CECP trail with architect ADR only (no false builder/implementor completeness).

## Consequences

- Operators and agents have an in-repo CDU-RA index and sectioned skeleton.
- Future schemas, Mirror implementations, and runtime gates can cite CDU-RA without overclaiming v0.1.
- Runtime enforcement of CDU-RA remains **out of scope** until separately implemented and evidenced.
