# ADR — Adopt CCALF v1.0 as declared framework docs

## Intent

Publish the complete Constitutional Cyber & AI Learning Framework (CCALF) v1.0 specification bundle in this repository for cross-product learning and competency stewardship alignment.

## Decision

1. Place the bundle at `docs/ccalf/` (and `docs/ccalf/domains/` for 520–550).
2. Treat adoption as **declared documentation**, not a CKL/engine conformance gate.
3. Document relationship: CCALF = learning/competency stewardship; MRS AGENTS.md + charter = agent/runtime binding law.
4. Do not modify protected constitutional paths.

## Consequences

- Learners and educators have a canonical in-repo CCALF index.
- Future domain specs can extend via CCALF-510 without touching engine governance.
- Runtime enforcement of CCALF remains **out of scope** until separately implemented and evidenced.
