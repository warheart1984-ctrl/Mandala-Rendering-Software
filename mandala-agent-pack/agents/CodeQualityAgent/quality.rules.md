# Code Quality Rules

1. File names must use PascalCase for classes, kebab-case for utilities.
2. Module boundaries must match directory structure.
3. No dead code — every export must be used or have a declared reason.
4. No unused imports.
5. Functions should be < 50 lines; complex logic should be broken down.
6. Comments should explain "why", not "what" — code should be self-documenting.
