# Naming Rules

1. Classes: PascalCase (e.g., `WebGPURenderer`, `PostProcessor`).
2. Functions/variables: camelCase (e.g., `isWebGPUSupported`, `renderFrame`).
3. Constants: UPPER_SNAKE_CASE (e.g., `SHARED_GPU_IMAGE_MAGIC`).
4. Files: match export name (e.g., `WebGPURenderer.js` exports `WebGPURenderer`).
5. Test files: `*.test.js` suffix, mirror source path.
