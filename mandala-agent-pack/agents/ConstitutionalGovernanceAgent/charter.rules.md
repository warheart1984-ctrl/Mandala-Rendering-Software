# Charter Rules

1. **charter.js** is the machine-readable source of truth.
2. Every organ must have a `status` of `"enforced"`, `"partial"`, or `"declared"`.
3. Drift between `charter.js` status and implementation status is a conformance violation.
4. Version must match across `charter.js`, `CITATION.cff`, and `.zenodo.json`.
5. 5 principles (P1-P5) must be present with correct IDs and non-empty text.
