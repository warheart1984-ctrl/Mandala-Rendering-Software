# Constitutional Invariants

1. **P1**: No execution without intent — every operation must have a declared intent ID.
2. **P2**: No state change without evidence — every mutation must have verifiable evidence.
3. **P3**: No authority without contract — every actor must operate under a defined contract.
4. **P4**: Replayable reality — every significant decision/render must be replayable.
5. **P5**: Sovereign independence — no vendor lock-in, proprietary deps, or cloud-specific code.
6. **Policy 1-7**: All runtime policies must be loaded and enforced by CKL.
7. **16/16 checks**: All conformance checks must pass in every release.
