# Documentation Standards

1. Every doc must have a status line: `declared`, `partial`, or `enforced`.
2. Every claim must be backed by an implementation or evidence reference.
3. Do not invent statuses — only use `declared`, `partial`, `enforced`.
4. Governance docs under `docs/governance/` do not amend `AGENTS.md`.
5. README files are created only when explicitly requested.
6. Use GitHub-flavored markdown; no emojis unless requested.
