Mandala Engine editor

Not Unreal Editor. Scrub certified t, inspect hash, switch observation organ. Physics edits require a proposal through AAIS.

Movie Lane does not own time. Live shader reload is a CLI stub (--organ).

CLI

node mandala/engine/editor/cli.mjs list --seed 7 --steps 4
node mandala/engine/editor/cli.mjs scrub --t 2 --seed 7 --steps 4
node mandala/engine/editor/cli.mjs hash --seed 7 --steps 4
node mandala/engine/editor/cli.mjs --organ MovieLane
node mandala/engine/editor/cli.mjs set-phi          # refused
node mandala/engine/editor/cli.mjs set-phi --propose  # still needs a real Chamber proposal
