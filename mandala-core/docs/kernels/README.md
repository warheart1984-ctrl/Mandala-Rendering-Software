# Starter Kernels

Assist-only HIP + GLSL kernels for Mandala constitutional rendering.

## Provided
- frosted_glass_microflake.hip / .glsl
- iridescent_thin_film.hip
- ocean_gerstner.hip
- hologram_shader.hip

All kernels are assist-only: compute evidence, no authority. RT4D validates results.

Add kernels to axiom-x-hip/src/kernels and compile with feature="hip".
