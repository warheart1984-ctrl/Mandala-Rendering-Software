How it works

One job: map a depth field into a hashed spatial token — not a chat wrapper.

  1. Feed chamber depth, opticalLength, or landmark-z (math path).
  2. Bin into an 8×8 or 16×16 grid with curvature and surface normals.
  3. Hash canonical JSON — same depth bytes, same token hash.
