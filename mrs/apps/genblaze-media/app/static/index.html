Optional path: GENBLAZE_IMAGE_BACKEND=rt4d → MRS RT4D path tracer → deterministic procedural 4D still (NOT text-to-image / not diffusion). Stills · NIM FLUX or RT4D

Prompt tips (FLUX.1-schnell): abstract geometry, mandalas, tesseracts, neon grids, and studio-lit objects usually work. Photoreal people / faces / skin often return blank black stills on this NIM path — describe the object and light, not a portrait. If a people-like prompt blanks, the service retries once with an abstract rewrite (disable with GENBLAZE_ABSTRACT_RETRY=0). Do not append feedback like “ok this not good” into the prompt.

RT4D renderer backend (GENBLAZE_IMAGE_BACKEND=rt4d, or NVIDIA fallback via GENBLAZE_IMAGE_FALLBACK_TO_RT4D=1): the prompt selects a procedural 4D scene archetype (keyword → surface / palette / camera), then the MRS RT4D CPU path tracer renders a deterministic PNG. Same prompt → same seed → same bytes. This is not text-to-image and not photoreal diffusion — it is a seeded 4D render with provenance (seed, scene id, camera, samples) in the manifest. Requires Node.js + renderer-core/scripts/render-still.mjs; see rt4d.available in /health for whether this running image has them.

Scene interpretation + path-traced full frame. Upload a photo or paste a prior generate run_id. The service emits a SceneSpecification (NIM vision when configured, else heuristic), validates it, then MRS path-traces a full PNG. This is not geometric reconstruction, depth recovery, or mesh from photo.

NIM Cosmos · video (CMM-NIM-Cosmos)

Prompt tips (Cosmos text-to-world): abstract / world-scale scenes (landscapes, geometry, light) work better than portraits. People and faces may blank or degrade. NVCF cold-start: Cosmos is often slower than FLUX on the first hit after Render or NIM idle — even with 600s+ timeouts, expect longer first-request latency; keep this tab open. Larger mp4 objects cost more B2 Class C traffic. This section appears when video is enabled (default when NVIDIA_API_KEY is set and GENBLAZE_VIDEO_ENABLED is unset; set GENBLAZE_VIDEO_ENABLED=0 for stills-only).
